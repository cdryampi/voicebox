## API Key Authentication

Voicebox supports optional API key authentication for remote deployments.

Set `VOICEBOX_API_KEY` in the backend environment and send:

```http
Authorization: Bearer <VOICEBOX_API_KEY>
```

If `VOICEBOX_API_KEY` is not configured, the backend remains open for local-only workflows.

## Media & SSE Access

Some clients (for example `<audio>` tags or `EventSource`) cannot always attach custom headers.
For these **GET** endpoints, Voicebox also accepts:

```text
?access_token=<VOICEBOX_API_KEY>
```

Examples:
- `/audio/{generation_id}?access_token=...`
- `/profiles/{profile_id}/avatar?access_token=...`
- `/models/progress/{model_name}?access_token=...`

For non-GET endpoints, use `Authorization: Bearer ...`.

## Local Usage

For local development:
- API runs on `http://127.0.0.1:17493`
- Leave `VOICEBOX_API_KEY` unset
- Keep server private to your machine/network
